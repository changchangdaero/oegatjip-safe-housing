# 외같집
외국인 대상 부동산 안심 거래 통합 솔루션 제공 플랫폼 

<img width="1768" height="990" alt="image" src="https://github.com/user-attachments/assets/414aab3b-c4cf-4d59-91d0-2461a9a0c0db" />


## 개발 배경

본 프로젝트는 창업 아이디어 캠프에서 기획한 아이디어를 바탕으로,
외국인이 국내 부동산 거래 과정에서 겪는 정보 비대칭과 계약 위험을 줄이기 위한 초기 MVP로 구축되었습니다.


## MVP 주요 기능

- 계약서 업로드 UI
- 계약서 및 등기부 문서 언어 선택
- 한국어, 영어, 중국어, 대만어, 일본어 지원
- AI 기반 계약 위험 분석 화면
- 외국인 대상 부동산 거래 체크리스트 제공
